How it works

  1. Pick an image on the left. Its prompt is on the right: Copy it into Gemini (1024 × 1024, flat magenta background), or change the wording and Save prompt so the manifest keeps yours.
  2. Drop the picture you get onto the frame (or click it). The background is keyed out here, in the browser: the flat colour around the border, then any big enclosed patch of the same colour (the white under a headband). Smaller patches are only flagged, because the whites of the eyes look the same on a white background: check them over black, red and the checkerboard, and click a leftover with the wand to remove it.
  3. Look at it where it will be used: the tokens, the Roster card, a Team slot, the dialogue box and the boss card for a portrait; the battlefield beside the code-drawn figure for a sprite. Flip if it faces the wrong way.
  4. Save to the game writes it to /incoming and runs the ingest (crop, resize, WebP); the previews then show the file the game will load. Nothing here is uploaded anywhere but this computer.

Needs the local server (npm run serve, or the app's preview). The list marks each image: ● done · ○ missing · ● flagged (saved with leftovers, or a prompt of your own).
